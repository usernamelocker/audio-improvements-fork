# Audio Improvements 1.3.4 — Minecraft 26.2 Fabric

A community-maintained port of [NamelessJu's Audio Improvements](https://github.com/NamelessJu/MC-Audio-Improvements-Mod), updated for Minecraft Java 26.2 with audio fixes and refreshed documentation.

## Requirements

| Component | Version |
|---|---|
| Minecraft Java | 26.2 |
| Java | 25 or newer |
| Fabric Loader | 0.19.3 or newer |
| Fabric API | A 26.2 build; tested with 0.161.0+26.2 |
| Mod Menu (optional) | 20.0.3 |
| VinURL (optional) | 2.6.0 for 26.2, with its required dependencies; tested with owo-lib 0.13.1+26.2 |

This is a client-only mod. No server installation is required.

## Installation and upgrading

1. Download **`audioimprovements-1.3.4+26.2.jar`** from the assets below.
2. Place it in your Minecraft 26.2 Fabric profile's `mods` folder alongside Fabric API. Replace any older Audio Improvements jar to avoid duplicates.
3. Keep `config/audioimprovements.json` to preserve your settings.
4. Open settings in-game with `/audioimprovements` or through Mod Menu.

The `-sources.jar` is for developers and should not be installed. `SHA256SUMS.txt` contains checksums for both jars. GitHub's Source code archives contain the tagged project, not an installable mod.

## Changes

- Port screen navigation and camera access to Minecraft 26.2.
- Update Fabric API, Mod Menu, and optional VinURL compatibility, including VinURL's changed playback signature.
- Correct the music-delay injection points so vanilla's delay clamp does not override custom music frequency.
- Include the earlier fix for fading music ignoring the music volume slider.
- Fix cleanup of stopped music-block channels.
- Respect the current buffer position when tracking direct OpenAL sound-position updates.
- Correct mono frame size and byte order when converting signed 16-bit stereo audio; leave unsupported sample formats unchanged.
- Close configuration readers, create missing configuration directories, and save repaired invalid entries.
- Pin the build tool versions, centralize version metadata, and update support links to this fork.
- Add regression tests, installation instructions, a changelog, and a runtime testing checklist.

Music fading, sound delay, and Doppler effects remain off by default for new configurations. Existing settings are retained.
